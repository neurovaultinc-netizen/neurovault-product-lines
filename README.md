# NeuroVault Product Lines

NeuroVault is a SaaS portfolio built for end users who want systems that think: products that detect patterns, explain signals, and predict what comes next.

This repository defines the initial product line strategy for the NeuroVault platform.

## Product portfolio

1. NeuroVault Insight
   - Pattern recognition and anomaly detection
   - Helps users understand what is happening in their data

2. NeuroVault Forecast
   - Predictive intelligence and forecasting
   - Helps users anticipate outcomes and adjust before they happen

3. NeuroVault Studio
   - Workflow and model configuration layer
   - Helps users shape their intelligence experiences and analysis pipelines

4. NeuroVault Copilot
   - AI guidance and action layer
   - Helps users ask better questions and move from insight to action

## Current priority

The first priority is NeuroVault Insight.

This is the foundation product because it delivers the clearest customer value immediately: the ability to discover hidden patterns, detect anomalies, and understand the signal in noisy information.

## Product line priorities

### Priority 1: NeuroVault Insight
Focus:
- detect patterns
- identify anomalies
- explain observations in plain language
- create trust in the output

### Priority 2: NeuroVault Forecast
Focus:
- forecast likely outcomes
- build predictive summaries
- support better planning and decision-making

### Priority 3: NeuroVault Studio
Focus:
- give users a control layer for building workflows
- connect datasets and logic
- support advanced use cases without requiring a data science team

### Priority 4: NeuroVault Copilot
Focus:
- turn insight into guided action
- respond to user questions in context
- summarize options and propose next steps

## Why this portfolio architecture works

The product line is designed to move from understanding to prediction to action.

It follows a clear customer journey:
- See patterns
- Anticipate outcomes
- Configure systems
- Act with confidence
